## 背景与问题

订单管理是跨境ERP的核心业务模块，涵盖订单接收、审核、合单拆单、波次拣货、发货全流程。当前问题：订单审核依赖人工，效率低且易出错；合单拆单规则不明确，导致发货混乱；波次拣货缺乏系统支持，仓库作业效率低。

## 目标与成功标准

1. 实现订单自动审核，支持地址/支付/库存三项校验
2. 建立合单拆单规则引擎，支持灵活配置
3. 实现波次拣货功能，支持仓库批量作业
4. 支持预售订单手动触发发货
5. 实现发货仓就近分配逻辑

## 业务规则

| 编号 | 条件 | 动作 | 结果 |
|------|------|------|------|
| BR-01 | 订单地址有效且支付成功且库存充足 | 自动审核通过 | 订单状态变为「待发货」 |
| BR-02 | 订单地址无效 | 审核失败 | 订单状态变为「审核失败」，提示地址问题 |
| BR-03 | 订单支付失败 | 审核失败 | 订单状态变为「审核失败」，提示支付问题 |
| BR-04 | 订单商品库存不足 | 审核失败 | 订单状态变为「审核失败」，提示库存问题 |
| BR-05 | 订单审核通过 | 预占库存 | 对应SKU库存预占数量增加 |
| BR-06 | 订单发货完成 | 释放预占库存 | 预占库存转为实际扣减 |
| BR-07 | 订单取消或超时未支付 | 释放预占库存 | 预占库存释放回可用库存 |
| BR-08 | 多个订单满足合单条件 | 执行合单 | 合并为一个订单，原订单标记为已合并 |
| BR-09 | 单个订单商品分仓库 | 执行拆单 | 按仓库拆分为多个子订单 |
| BR-10 | 波次拣货规则触发 | 生成波次 | 自动分配订单到波次 |
| BR-11 | 发货仓分配 | 就近分配原则 | 优先分配距离收货地址最近的仓库 |
| BR-12 | 预售订单手动触发 | 释放库存并发货 | 需人工确认后执行 |

## 状态、异常与边界

### 订单状态流转

```
待审核(pending) → [自动审核] → 审核通过(approved) → [发货] → 已发货(shipped) → [签收] → 已完成(completed)
待审核(pending) → [审核失败] → 审核失败(rejected) → [处理] → 待审核
审核通过(approved) → [取消] → 已取消(cancelled)
已发货(shipped) → [退货] → 退货中(returning) → [完成] → 已退货(returned)
```

### 波次状态流转

```
待拣货(pending) → [开始拣货] → 拣货中(picking) → [完成] → 已完成(completed)
```

### 异常处理

- 自动审核失败：订单进入人工审核队列，显示具体失败原因
- 合单失败：记录失败原因，支持手动处理
- 拣货异常：支持标记异常商品，生成异常报告
- 发货仓分配失败：使用默认仓库或提示手动选择

### 边界情况

- 订单金额为0：正常处理，跳过支付校验
- 预售订单：允许审核通过但延迟发货
- 跨境订单：地址格式特殊处理
- 超大订单：支持分批拣货

## 字段、内容与交互要求

### 订单列表页

- 顶部：搜索框（订单号/商品名称）、筛选条件（状态/平台/时间范围）
- 操作区：批量审核、批量发货、导出
- 列表：订单号、平台图标、商品信息、金额、状态、操作（详情/审核/发货）
- 分页：支持每页10/20/50条

### 订单详情页

- 基本信息：订单号、下单时间、订单状态
- 买家信息：买家昵称、联系方式
- 收货地址：省市区详细地址
- 商品列表：商品图片、名称、规格、数量、单价
- 支付信息：支付方式、支付时间、支付金额
- 物流信息：物流方式、物流单号、物流状态
- 操作日志：审核记录、发货记录

### 合单拆单规则配置页

- 规则列表：规则名称、类型、状态、操作
- 新增/编辑表单：
  - 规则名称
  - 规则类型（合并/拆分）
  - 触发条件（订单金额范围、收货地址、商品类型等）
  - 执行动作（合并订单、拆分订单）
  - 优先级
  - 状态开关

### 波次拣货列表页

- 待拣货波次列表：波次号、仓库、订单数、商品数、状态
- 拣货操作：开始拣货、标记完成、异常处理
- 进度展示：已拣/总数进度条

### 波次拣货规则配置页

- 规则列表：规则名称、条件、状态
- 新增/编辑表单：
  - 规则名称
  - 生成条件（时间范围、仓库、订单类型）
  - 最大订单数
  - 最大商品数
  - 优先级
