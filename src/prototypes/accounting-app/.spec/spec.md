# 记账APP原型主规格

## 当前方案

- 原型意图：移动端单账本记账应用，支持手机号验证码登录、微信登录，数据云端实时同步
- 使用场景：个人用户日常记账、收支统计、预算管理
- 当前表达：完整实现登录、记账、统计、我的四大模块

## 事实与输入

### 用户确认事实

- 目标用户：个人用户
- 数据来源：手动输入为主，AI语音为辅
- 素材来源：系统预置 + AI生成
- 原型范围：完整实现所有页面
- 设计风格：简约现代（使用现有项目框架）
- 设计基底：ThemeShell中性色系统 + Tailwind CSS v4

### 参考资料

- 用户提供的完整需求文档（Vibe Coding适配版）
- 项目现有ThemeShell组件和颜色系统
- Tailwind CSS v4样式框架

### 当前假设

- 使用项目现有ThemeShell中性色系统（黑白灰）
- 金额显示规则：最多精确到小数点后2位，收入绿色、支出红色
- 文本限制：备注最多50字，昵称最多20字
- 时间规则：记账时间精确到秒，列表展示精确到分（HH:mm）

## 原型范围

### 本次呈现

1. **登录模块**
   - 登录页（手机号输入、获取验证码、微信登录、用户协议）
   - 验证码页（4位验证码输入、倒计时）

2. **记账Tab模块**
   - 主页面（筛选栏、统计卡片、账单列表、悬浮记账按钮）
   - 普通记账页（金额输入、分类选择、时间选择、备注）
   - AI记账页（录音按钮、预览账单列表）
   - 账单编辑页（回显数据、保存、删除）

3. **统计Tab模块**
   - 页面结构（时间选择、收支切换、分享按钮）
   - 收支总览、分类占比饼图、收支趋势折线图、分类排行榜
   - 分享H5页面（5页上下滑动）

4. **我的Tab模块**
   - 页面结构（个人信息、功能列表）
   - 个人信息编辑（头像、昵称）
   - 账号与安全（修改手机号、微信绑定/解绑）
   - 自定义分类配置（收入/支出Tab、拖动排序、新增分类）
   - 预算设置（月度预算、年度预算自动计算）
   - 记账提醒（开关、时间设置）
   - 隐私协议、关于应用
   - 退出登录

### 本次不呈现

- 后端API对接（使用模拟数据）
- 真实微信登录授权
- 真实短信验证码发送
- AI语音识别功能
- 云端数据同步

## 交互与状态方案

| 对象/场景 | 前置状态 | 用户操作 | 原型表现 | 后续状态 |
| --- | --- | --- | --- | --- |
| 未勾选协议 | 协议未勾选 | 点击获取验证码或微信登录 | 弹出确认弹窗 | 用户确认后自动勾选协议 |
| 验证码输入 | 验证码页已打开 | 输入满4位验证码 | 自动校验 | 校验失败输入框标红 |
| 倒计时 | 已发送验证码 | 等待60秒 | 重新获取按钮置灰 | 倒计时结束恢复可点击 |
| 普通记账 | 记账页已打开 | 金额为空时点击保存 | 保存按钮置灰 | 金额不为0时恢复可点击 |
| 分类选择 | 记账页已打开 | 点击更多分类 | 弹出底部弹窗 | 显示全部分类 |
| 新增分类 | 分类弹窗已打开 | 点击新增分类 | 弹出新增弹窗 | 保存后自动选中该分类 |
| 账单列表 | 记账Tab主页面 | 列表为空 | 显示空状态插画 | 提示文案 |
| 无网络 | 任何页面 | 进入页面时无网络 | 显示缺省页 | 图标+文字+重试按钮 |
| 退出登录 | 我的Tab页面 | 点击退出登录 | 弹出二次确认弹窗 | 确认后清空登录状态 |

## 设计基底与原型特有调整

- 采用的设计基底：项目现有ThemeShell中性色系统
- 继承方式：使用ThemeShell颜色系统和Tailwind CSS v4
- 本原型特有调整：
  - 金额显示：收入绿色(#10B981)、支出红色(#EF4444)
  - 主品牌色：蓝色(#3B82F6)用于主按钮和高亮
  - 背景色：使用ThemeShell的bgPrimary(#FFFFFF)和bgSecondary(#FAFAFA)
  - 文字色：使用ThemeShell的textPrimary、textSecondary、textTertiary
  - 边框色：使用ThemeShell的border和borderLight
