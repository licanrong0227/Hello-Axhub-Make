## 背景与问题

系统门户是跨境ERP的统一入口，用户登录后通过门户导航访问10大业务模块。当前需要明确门户的登录流程、导航结构、iframe嵌入机制以及用户账号管理功能。

## 目标与成功标准

1. 提供统一的登录入口，支持账号密码登录
2. 通过左侧导航菜单快速访问所有业务模块
3. 右侧内容区通过iframe加载对应模块页面，避免页面跳转
4. 支持修改密码和退出登录

## 用户、角色与场景

| 角色 | 场景 |
|------|------|
| 所有用户 | 登录系统、通过导航访问各模块 |
| 所有用户 | 修改密码、退出登录 |

## 范围

### 本次包含

- 登录页面（账号密码表单、系统Logo、版权信息）
- 主导航框架（左侧菜单、顶部栏、内容区iframe）
- 修改密码功能（两步流程：验证旧密码→设置新密码）
- 退出登录功能（二次确认）

### 不在本次范围

- SSO/ OAuth第三方登录
- 多语言切换
- 主题皮肤切换

## 用户故事

1. 作为系统用户，我希望通过账号密码登录系统，从而安全访问ERP功能
2. 作为系统用户，我希望通过左侧导航快速切换业务模块，从而高效完成工作
3. 作为系统用户，我希望修改自己的登录密码，从而保障账号安全
4. 作为系统用户，我希望退出登录，从而保护数据安全

## 数据模型

### UserSession（用户会话）

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | string | 用户ID |
| username | string | 用户名 |
| displayName | string | 显示名称 |
| isLoggedIn | boolean | 登录状态 |

### LoginCredentials（登录凭证）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| account | string | 是 | 账号 |
| password | string | 是 | 密码 |

### PasswordChange（密码修改）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| oldPassword | string | 是 | 旧密码 |
| newPassword | string | 是 | 新密码 |
| confirmPassword | string | 是 | 确认新密码 |

## 业务规则

| 编号 | 条件 | 动作 | 结果 |
|------|------|------|------|
| BR-01 | 用户输入账号密码点击登录 | 系统验证凭证 | 验证通过跳转主页，失败提示错误 |
| BR-02 | 修改密码时旧密码验证 | 验证旧密码正确性 | 正确进入设置新密码步骤，失败提示错误 |
| BR-03 | 新密码与确认密码不一致 | 阻止提交 | 提示「两次输入密码不一致」 |
| BR-04 | 用户点击退出登录 | 弹出二次确认 | 确认后清除会话返回登录页 |
| BR-05 | 导航菜单点击叶节点 | 加载iframe | 右侧内容区显示对应模块页面 |
| BR-06 | 页面在iframe中加载 | 检测嵌入环境 | 自动隐藏侧边栏和顶栏，仅显示内容 |

## 状态、异常与边界

### 登录状态流转

```
未登录 → [输入凭证] → 登录中 → [验证通过] → 已登录 → [退出] → 未登录
```

### 异常处理

- 账号或密码错误：提示「账号或密码错误」
- 网络异常：提示「网络异常，请稍后重试」
- 修改密码失败：提示具体错误原因

## 字段、内容与交互要求

### 登录页

- 居中卡片布局，包含：
  - 蓝色圆角Logo图标（Layers图标）
  - 系统名称「跨境ERP系统」
  - 英文副标题「Cross-border ERP System」
  - 账号输入框（带User图标）
  - 密码输入框（带Lock图标）
  - 登录按钮（蓝色满宽）
  - 底部版权「© 2026 跨境ERP系统 版权所有」
- 背景：淡蓝色渐变

### 主导航框架

- **左侧边栏**：
  - 顶部：系统名称 + 折叠按钮
  - 菜单：10个模块分组，每组下有子菜单项
  - 支持折叠/展开
- **顶部栏**：
  - 左侧：搜索框
  - 右侧：消息通知（红点数字）、用户头像下拉菜单
- **内容区**：
  - 面包屑导航
  - iframe加载目标页面

### 用户菜单（头像悬停）

- 修改密码
- 退出登录（红色文字）

### 修改密码弹窗

- 步骤条：① 验证旧密码 → ② 设置新密码
- 第一步：旧密码输入框
- 第二步：新密码 + 确认新密码输入框
- 按钮：取消、下一步/确认修改

### 退出登录确认

- 居中弹窗，红色图标
- 提示文字「确认退出登录？」「退出后需要重新登录才能使用系统」
- 按钮：取消、确认退出（红色）

## 验收标准与来源追溯

- 产品验收：登录流程完整，导航可正常切换模块，修改密码和退出登录功能正常
- 设计验收：界面布局合理，交互流畅
- 实现验收：iframe嵌入正常工作，嵌入时自动隐藏外层导航
- 来源追溯：PRD文档 §3.0 首页工作台、§3.9 系统管理
