## 背景与问题

数据看板是跨境ERP的决策支撑模块，为管理层和运营人员提供经营概览、销售分析、库存分析和物流分析能力。当前问题：经营数据分散在各模块，缺乏统一视角；同比环比计算依赖手工Excel，效率低且易出错；报表维度固定，无法按需钻取明细；数据权限未与组织架构绑定，存在越权查看风险。

## 目标与成功标准

1. 建立经营看板页，一屏展示核心经营指标及趋势
2. 实现销售报表页，支持多维度销售数据分析与钻取
3. 实现库存报表页，展示库存结构、周转率与预警分析
4. 实现物流报表页，分析物流时效、费用与渠道效率
5. 建立数据权限范围控制，按角色和组织架构限定可见数据
6. 实现同比环比自动计算，支持日/周/月/季/年多时间粒度

## 用户、角色与场景

| 角色 | 场景 |
|------|------|
| 管理层 | 查看经营看板，了解整体业务趋势，做决策参考 |
| 运营人员 | 查看销售报表，分析各平台/店铺销售表现 |
| 仓库人员 | 查看库存报表，分析库存周转与预警 |
| 物流人员 | 查看物流报表，分析物流时效与费用 |
| 财务人员 | 查看经营看板中的财务指标，核对收入成本 |

## 范围

### 本次包含

- 经营看板页（核心指标卡片、趋势图表、同比环比）
- 销售报表页（销售额/订单量/客单价/退货率多维分析）
- 库存报表页（库存结构/周转率/预警统计/库龄分析）
- 物流报表页（时效分析/费用分析/渠道效率/妥投率）
- 数据权限范围控制（按角色+组织架构限定数据范围）
- 同比环比计算引擎（支持多时间粒度）
- 钻取查询（从汇总到明细逐层下钻）
- 报表导出（Excel/PDF）

### 不在本次范围

- 自定义报表设计器（延后）
- 数据预测与AI分析
- 实时数据大屏
- 报表订阅与定时推送

## 用户故事

1. 作为管理层，我希望在经营看板看到今日/本周/本月核心指标及同比环比，从而快速了解业务健康度
2. 作为运营人员，我希望按平台/店铺/时间维度筛选销售数据，从而分析各渠道表现
3. 作为运营人员，我希望从销售汇总数据钻取到订单明细，从而定位具体问题订单
4. 作为仓库人员，我希望查看各仓库库存周转率和库龄分布，从而优化库存结构
5. 作为物流人员，我希望对比不同物流渠道的时效和费用，从而选择最优物流方案
6. 作为管理员，我希望按角色配置数据权限范围，从而确保数据安全

## 能力与信息架构

```
数据看板
├── 经营看板页
│   ├── 核心指标卡片（今日销售额/订单量/客单价/利润率）
│   ├── 趋势图表（销售趋势/利润趋势/订单趋势）
│   ├── 同比环比指标
│   └── 钻取入口（点击指标跳转对应报表）
├── 销售报表页
│   ├── 筛选区（时间/平台/店铺/商品类目）
│   ├── 汇总数据（销售额/订单量/客单价/退货率）
│   ├── 趋势图表（折线图/柱状图）
│   ├── 排行榜（Top商品/Top店铺/Top平台）
│   └── 钻取明细（点击汇总→查看明细订单）
├── 库存报表页
│   ├── 筛选区（仓库/SKU/类目）
│   ├── 库存结构（各仓库库存占比/类目库存分布）
│   ├── 周转率分析（SKU维度/仓库维度）
│   ├── 预警统计（低库存/滞销/临期）
│   └── 库龄分析（0-30天/31-60天/61-90天/90天以上）
└── 物流报表页
    ├── 筛选区（时间/物流商/渠道/国家）
    ├── 时效分析（平均发货时长/平均签收时长）
    ├── 费用分析（运费总额/单均运费/费用趋势）
    ├── 渠道效率（各渠道妥投率/签收率）
    └── 钻取明细（点击渠道→查看具体运单）
```

## 业务规则

| 编号 | 条件 | 动作 | 结果 |
|------|------|------|------|
| BR-01 | 用户请求查看报表 | 校验数据权限范围 | 按用户角色和组织架构过滤数据 |
| BR-02 | 超级管理员查看报表 | 不限制数据范围 | 返回全量数据 |
| BR-03 | 普通用户查看报表 | 按数据范围过滤 | 仅返回权限范围内的数据 |
| BR-04 | 数据范围为空 | 返回空数据集 | 提示「当前权限范围无数据」 |
| BR-05 | 请求同比数据 | 计算去年同期数据 | 同比增长率=(本期-去年同期)/去年同期×100% |
| BR-06 | 请求环比数据 | 计算上期数据 | 环比增长率=(本期-上期)/上期×100% |
| BR-07 | 上期数据为0 | 同比/环比无法计算 | 显示「--」，不显示具体数值 |
| BR-08 | 用户点击汇总数据 | 触发钻取查询 | 按钻取层级逐层下钻 |
| BR-09 | 钻取到最细粒度 | 展示明细数据 | 展示订单/SKU/运单明细列表 |
| BR-10 | 报表数据量超过阈值 | 异步计算 | 提示「数据量较大，正在生成，请稍后查看」 |
| BR-11 | 用户导出报表 | 生成导出文件 | 支持Excel/PDF格式 |
| BR-12 | 导出数据量超过上限 | 阻止导出 | 提示「导出数据量超过限制，请缩小筛选范围」 |

## 状态、异常与边界

### 报表生成状态

```
查询中(querying) → [数据聚合] → 生成中(generating) → [完成] → 已生成(completed)
查询中(querying) → [超时] → 超时(timeout)
生成中(generating) → [失败] → 失败(failed) → [重试] → 生成中(generating)
```

### 异常处理

- 数据源查询超时：使用缓存数据，标记数据时效
- 报表计算异常：记录错误日志，提示用户稍后重试
- 导出失败：记录失败原因，支持重新导出
- 钻取层级超限：提示「已到最细粒度，无法继续钻取」
- 权限校验失败：返回空数据，提示无权限

### 边界情况

- 无数据时：显示空态图表，提示「暂无数据，请调整筛选条件」
- 时间范围为空：默认选择近7天
- 筛选条件冲突：提示「筛选条件有误，请重新选择」
- 同比/环比基准期无数据：显示「--」
- 汇总数据为0：正常显示，不隐藏
- 并发查询同一报表：排队处理，返回最新结果

## 字段、内容与交互要求

### 经营看板页

- **指标卡片区**：4个核心指标卡片（今日销售额、订单量、客单价、利润率），每个卡片展示当前值、同比变化（↑↓箭头+百分比）
- **趋势图表区**：销售趋势折线图（支持切换日/周/月维度），利润趋势柱状图，订单量趋势折线图
- **店铺排行**：当日/本周/本月 Top10 店铺销售额排行
- **快捷跳转**：点击指标卡片跳转对应报表页

### 销售报表页

- **筛选区**：时间范围选择器、平台下拉、店铺多选、类目多选、对比类型（无/同比/环比）
- **汇总数据区**：销售额、订单量、客单价、退货率、毛利率，各含同比环比
- **趋势图表区**：销售趋势折线图（支持切换对比维度），类目占比饼图
- **排行榜**：Top10商品、Top10店铺、Top10平台
- **明细列表**：支持从汇总数据点击钻取到订单明细

### 库存报表页

- **筛选区**：仓库多选、SKU搜索、类目多选
- **库存结构区**：各仓库库存占比饼图，类目库存分布柱状图
- **周转分析区**：平均周转率、周转天数趋势图
- **预警统计区**：低库存SKU数量、滞销SKU数量、预警等级分布
- **库龄分析区**：库龄分布柱状图（0-30/31-60/61-90/90+天）

### 物流报表页

- **筛选区**：时间范围、物流商多选、渠道多选、国家多选
- **时效分析区**：平均发货时长、平均签收时长趋势图
- **费用分析区**：运费总额趋势、单均运费趋势、费用占比饼图
- **渠道效率区**：各渠道妥投率对比、签收率对比
- **异常统计区**：丢失件数、破损件数、退回件数

### 通用交互要求

- 图表支持鼠标悬停显示详细数值
- 筛选条件变更后自动刷新图表
- 支持全屏查看图表
- 数据加载中显示骨架屏
- 数据异常时显示错误提示并支持重试

## 验收标准与来源追溯

- 产品验收：经营看板核心指标展示正确，同比环比计算准确，钻取查询逻辑正确
- 设计验收：图表布局清晰，数据层次分明，交互流畅
- 实现验收：数据权限控制生效，不同角色看到不同范围数据，导出功能正常
- 来源追溯：PRD文档 §3.8 数据看板

## 开放问题

- 经营看板的指标卡片是否支持自定义配置待确认
- 同比环比的基准期计算方式（自然周/自然月）待确认
- 报表数据的缓存策略和更新频率待确认
- 导出文件的格式模板和样式待确认
- 钻取查询的最大层级深度待确认
- 数据权限中「区域」的定义维度（按国家/按仓库群）待确认
