## 背景与问题

工作台首页是用户登录后的默认落地页，需要聚合展示待办事项、业务提醒、快捷入口和核心数据，帮助用户快速了解业务状态并进入工作。

## 目标与成功标准

1. 一屏展示当前用户所有待办事项，支持快速跳转处理
2. 实时展示业务异常提醒，确保问题及时处理
3. 提供快捷入口，支持自定义常用功能
4. 展示核心经营指标，支持数据概览

## 用户、角色与场景

| 角色 | 场景 |
|------|------|
| 运营人员 | 查看待处理订单、刊登失败提醒 |
| 仓库人员 | 查看库存预警、待发货订单 |
| 采购人员 | 查看采购建议、库存预警 |
| 管理员 | 查看全局数据概览 |

## 范围

### 本次包含

- 待办事项区（按类型分组展示）
- 提醒通知区（库存预警、授权到期等）
- 快捷入口区（用户自定义）
- 核心数据概览（订单量、销售额等）

### 不在本次范围

- 自定义仪表盘布局拖拽
- 数据导出功能

## 用户故事

1. 作为运营人员，我希望在工作台看到待审批单据和异常订单，从而快速处理紧急事务
2. 作为仓库人员，我希望看到库存预警提醒，从而及时补货避免断货
3. 作为管理员，我希望看到核心经营指标，从而了解业务整体状况

## 数据模型

### TodoItem（待办事项）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 待办ID |
| type | enum | 类型：approval/exception/aftersale |
| title | string | 标题 |
| count | number | 数量 |
| targetUrl | string | 跳转链接 |

### Notification（提醒通知）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 通知ID |
| type | enum | 类型：inventory_warning/auth_expire/publish_fail/sync_fail |
| title | string | 标题 |
| message | string | 内容摘要 |
| isRead | boolean | 是否已读 |
| createdAt | datetime | 创建时间 |

### QuickEntry（快捷入口）

| 字段 | 类型 | 说明 |
|------|------|------|

| label | string | 显示名称 |
| icon | string | 图标 |
| targetUrl | string | 跳转链接 |
| sortOrder | number | 排序 |

### DashboardStats（核心数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| todayOrders | number | 今日订单量 |
| todaySales | number | 今日销售额 |
| weekOrders | number | 本周订单量 |
| weekSales | number | 本周销售额 |
| pendingShipment | number | 待发货订单数 |
| inventoryWarning | number | 库存预警数 |
| pendingApproval | number | 待审批单据数 |
| pendingAftersale | number | 待处理售后数 |

## 业务规则

| 编号 | 条件 | 动作 | 结果 |
|------|------|------|------|
| BR-01 | 用户登录系统 | 自动拉取待办数据 | 按类型分组展示待办事项 |
| BR-02 | 库存低于安全库存 | 自动生成预警 | 提醒通知区展示库存预警 |
| BR-03 | 授权到期时间<7天 | 自动生成提醒 | 提醒通知区展示授权到期提醒 |
| BR-04 | 刊登任务失败 | 自动生成提醒 | 提醒通知区展示刊登失败提醒 |
| BR-05 | 用户点击待办事项数字 | 跳转对应列表页 | 直接进入处理页面 |
| BR-06 | 用户点击快捷入口 | 跳转对应功能页 | 进入目标功能 |
| BR-07 | 数据权限控制 | 按权限范围统计 | 超管看全量，普通用户看权限范围 |

## 状态、异常与边界

### 数据加载状态

- 首次加载：显示骨架屏
- 加载完成：显示真实数据
- 加载失败：显示错误提示，支持重试

### 空态处理

- 无待办事项：显示「暂无待办事项」
- 无提醒通知：显示「暂无提醒」
- 无快捷入口：显示引导添加提示

## 字段、内容与交互要求

### 待办事项区

- 按类型分组：待审批单据、待处理异常订单、待处理售后工单
- 每组显示数量角标
- 点击数字直接跳转对应列表页
- 支持一键收起/展开

### 提醒通知区

- 提醒类型：库存预警、授权到期、刊登失败、同步失败
- 未读提醒标红展示
- 点击提醒跳转对应处理页

### 快捷入口区

- 图标+文字的网格布局
- 支持用户自定义添加/删除
- 支持拖拽排序

### 核心数据概览

- 卡片式布局，展示关键指标
- 支持切换「当日」「本周」维度
- 点击指标卡片跳转对应明细报表

## 验收标准与来源追溯

- 产品验收：待办事项正确展示且可跳转，提醒通知实时更新，快捷入口可自定义
- 设计验收：布局清晰，信息层次分明
- 实现验收：数据按权限范围正确过滤
- 来源追溯：PRD文档 §3.0.1 工作台首页
