# 登录模块 PRD

## 背景与问题

记账APP需要为用户提供安全便捷的登录方式，支持手机号验证码登录和微信登录两种方式。当前问题包括：
- 用户需要快速进入应用开始记账
- 需要支持多种登录方式满足不同用户需求
- 需要处理用户协议确认流程

## 目标与成功标准

- 用户能够通过手机号验证码快速登录
- 用户能够通过微信一键登录
- 用户协议确认流程清晰明确
- 登录过程流畅，无卡顿

## 用户、角色与场景

| 用户/角色 | 使用场景 | 核心任务 |
| --- | --- | --- |
| 新用户 | 首次使用应用 | 选择登录方式，完成协议确认 |
| 老用户 | 再次使用应用 | 快速登录，进入主界面 |
| 微信用户 | 习惯使用微信登录 | 一键微信授权登录 |

## 范围

### 本次包含

1. **登录页面**
   - Logo和Slogan展示
   - 手机号输入框
   - 获取验证码按钮
   - 微信登录按钮
   - 用户协议勾选框

2. **验证码页面**
   - 返回按钮
   - 4位验证码输入框
   - 倒计时显示
   - 重新获取验证码按钮

3. **协议确认弹窗**
   - 用户协议确认弹窗
   - 同意并继续按钮
   - 取消按钮

### 不在本次范围

- 真实短信验证码发送（使用模拟数据）
- 真实微信登录授权（使用模拟数据）
- 密码登录方式
- 第三方账号绑定

## 用户故事

1. 作为新用户，我希望通过手机号快速注册并登录，从而开始使用记账功能
2. 作为微信用户，我希望一键微信登录，从而避免输入手机号的麻烦
3. 作为用户，我希望清楚了解用户协议内容，从而保护自己的权益

## 业务规则

### 登录规则

| 规则ID | 规则描述 | 条件 | 动作 | 结果 |
| --- | --- | --- | --- | --- |
| LR-001 | 手机号格式验证 | 输入手机号 | 11位数字验证 | 格式正确时按钮可点击 |
| LR-002 | 协议确认要求 | 未勾选协议 | 点击登录按钮 | 弹出确认弹窗 |
| LR-003 | 验证码发送 | 已勾选协议 | 点击获取验证码 | 发送验证码，进入验证码页面 |
| LR-004 | 微信登录 | 未勾选协议 | 点击微信登录 | 弹出确认弹窗 |
| LR-005 | 验证码验证 | 输入4位验证码 | 自动验证 | 验证通过进入主页 |

### 状态规则

| 规则ID | 规则描述 | 状态转换 |
| --- | --- | --- |
| SR-001 | 登录按钮状态 | 未输入手机号时禁用，输入后可用 |
| SR-002 | 倒计时状态 | 发送验证码后开始60秒倒计时 |
| SR-003 | 验证码错误状态 | 验证失败时显示错误提示 |

## 状态、异常与边界

### 页面状态

| 页面 | 状态 | 描述 |
| --- | --- | --- |
| 登录页 | 默认状态 | 手机号为空，协议未勾选 |
| 登录页 | 输入状态 | 已输入手机号，协议未勾选 |
| 登录页 | 可登录状态 | 已输入手机号，已勾选协议 |
| 验证码页 | 输入状态 | 等待输入验证码 |
| 验证码页 | 错误状态 | 验证码输入错误 |
| 验证码页 | 倒计时状态 | 等待重新获取验证码 |

### 异常处理

| 异常场景 | 处理方式 |
| --- | --- |
| 手机号格式错误 | 输入框下方提示格式错误 |
| 验证码错误 | 显示错误提示，1秒后消失 |
| 网络连接失败 | 显示重试按钮 |
| 微信授权失败 | 返回登录页，提示授权失败 |

## 字段、内容与交互要求

### 页面结构

1. **登录页**
   - 顶部：Logo + 应用名称 + Slogan
   - 中部：手机号输入框 + 获取验证码按钮
   - 分割线："或"
   - 底部：微信登录按钮
   - 协议区：用户协议勾选框

2. **验证码页**
   - 顶部：返回按钮 + 标题 + 提示文案
   - 中部：4位验证码输入框
   - 底部：倒计时/重新获取按钮

### 交互要求

1. **手机号输入**
   - 输入框支持数字键盘
   - 最大长度11位
   - 实时格式验证

2. **验证码输入**
   - 自动聚焦第一个输入框
   - 输入完成后自动提交
   - 支持退格删除

3. **协议确认**
   - 点击协议文字可查看详情
   - 弹窗确认后自动勾选协议
