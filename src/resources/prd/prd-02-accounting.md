# 记账模块 PRD

## 背景与问题

记账APP的核心功能是帮助用户记录日常收支，需要提供便捷的记账方式。当前问题包括：
- 用户需要快速记录收入和支出
- 需要支持手动记账和AI语音记账两种方式
- 需要提供账单管理和分类配置功能

## 目标与成功标准

- 用户能够快速记录收入和支出
- 用户能够通过AI语音智能记账
- 用户能够查看和编辑已有账单
- 用户能够自定义分类管理

## 用户、角色与场景

| 用户/角色 | 使用场景 | 核心任务 |
| --- | --- | --- |
| 日常记账用户 | 消费后立即记账 | 快速记录支出金额和分类 |
| 收入记录用户 | 收到工资或奖金 | 记录收入来源和金额 |
| 语音记账用户 | 不方便手动输入 | 通过语音描述自动记账 |
| 账单管理用户 | 查看历史账单 | 编辑或删除错误账单 |

## 范围

### 本次包含

1. **记账Tab主页面**
   - 筛选栏（时间、分类）
   - 统计卡片（收支概览、预算进度）
   - 账单列表（按日期分组）
   - 悬浮记账按钮

2. **普通记账页**
   - 收入/支出切换
   - 金额输入
   - 分类选择（网格展示）
   - 时间选择
   - 备注输入
   - 保存按钮

3. **AI记账页**
   - 文本输入框
   - 识别按钮
   - 示例描述
   - 处理状态显示

4. **账单编辑页**
   - 账单信息回显
   - 编辑功能
   - 删除功能
   - 保存功能

5. **分类管理页**
   - 收入/支出分类切换
   - 系统预置分类展示
   - 自定义分类管理
   - 新增分类功能

### 不在本次范围

- 真实AI语音识别（使用模拟数据）
- 账单数据云端同步
- 批量导入导出账单
- 账单统计报表导出

## 用户故事

1. 作为日常记账用户，我希望快速记录一笔支出，从而保持记账习惯
2. 作为收入记录用户，我希望记录工资收入，从而了解月度收支情况
3. 作为语音记账用户，我希望通过语音描述自动记账，从而节省输入时间
4. 作为账单管理用户，我希望编辑错误账单，从而保证账目准确

## 业务规则

### 记账规则

| 规则ID | 规则描述 | 条件 | 动作 | 结果 |
| --- | --- | --- | --- | --- |
| AR-001 | 金额输入验证 | 输入金额 | 数值验证 | 金额必须大于0 |
| AR-002 | 分类必填验证 | 保存账单 | 分类验证 | 分类不能为空 |
| AR-003 | 备注长度限制 | 输入备注 | 字符计数 | 最多50个字符 |
| AR-004 | 时间默认值 | 新建账单 | 自动填充 | 默认为当前时间 |
| AR-005 | 类型切换 | 切换收入/支出 | 分类重置 | 清空已选分类 |

### 分类规则

| 规则ID | 规则描述 | 条件 | 动作 | 结果 |
| --- | --- | --- | --- | --- |
| CR-001 | 系统分类保护 | 删除分类 | 检查类型 | 系统分类不可删除 |
| CR-002 | 分类唯一性 | 新增分类 | 重复检查 | 同类型下分类名不能重复 |
| CR-003 | 分类图标 | 新增分类 | AI生成 | 可通过AI生成分类图标 |

## 状态、异常与边界

### 页面状态

| 页面 | 状态 | 描述 |
| --- | --- | --- |
| 记账主页面 | 空状态 | 没有账单记录 |
| 记账主页面 | 有数据状态 | 显示账单列表 |
| 普通记账页 | 输入中 | 正在输入金额和分类 |
| 普通记账页 | 可保存状态 | 金额和分类已填写 |
| AI记账页 | 识别中 | 正在处理语音输入 |
| AI记账页 | 识别完成 | 显示识别结果 |
| 分类管理页 | 空状态 | 没有自定义分类 |
| 分类管理页 | 有数据状态 | 显示分类列表 |

### 异常处理

| 异常场景 | 处理方式 |
| --- | --- |
| 金额输入非法字符 | 自动过滤非数字字符 |
| 分类选择为空 | 保存按钮禁用 |
| 网络连接失败 | 显示重试按钮 |
| AI识别失败 | 提示重新输入 |

## 字段、内容与交互要求

### 页面结构

1. **记账主页面**
   - 顶部：筛选栏（时间、分类）
   - 中部：统计卡片（收支概览、预算进度）
   - 底部：账单列表（按日期分组）
   - 浮层：悬浮记账按钮

2. **普通记账页**
   - 顶部：返回按钮 + 收入/支出切换
   - 中部：金额输入框
   - 底部：分类网格 + 表单（时间、备注）
   - 底部：保存按钮

3. **AI记账页**
   - 顶部：返回按钮 + 标题
   - 中部：文本输入框
   - 底部：识别按钮 + 示例描述

4. **账单编辑页**
   - 顶部：返回按钮 + 收入/支出切换
   - 中部：金额输入框 + 分类选择
   - 底部：表单（时间、备注）
   - 底部：保存/删除按钮

### 交互要求

1. **金额输入**
   - 支持小数点输入
   - 最多精确到2位小数
   - 实时格式验证

2. **分类选择**
   - 网格展示前8个分类
   - 点击"更多"展开全部分类
   - 支持新增自定义分类

3. **账单列表**
   - 按日期分组显示
   - 支持点击编辑
   - 显示金额正负号
