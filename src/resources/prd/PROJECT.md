# 记账APP

## 产品概览

- 一句话定位：移动端单账本记账应用，支持手机号验证码登录、微信登录，数据云端实时同步
- 产品背景：为个人用户提供便捷的记账工具，支持手动输入和AI语音记账，实现收支管理、统计分析和预算控制
- 产品目标：帮助用户轻松记录日常收支，提供智能理财建议，实现财务可视化管理

## 用户与场景

| 用户/角色 | 使用场景 | 核心任务 |
| --- | --- | --- |
| 个人用户 | 日常记账、收支统计、预算管理 | 记录收入支出、查看统计报表、设置预算提醒 |

## 产品范围

### 包含

1. **登录模块**
   - 登录页（手机号输入、获取验证码、微信登录、用户协议）
   - 验证码页（4位验证码输入、倒计时）

2. **记账Tab模块**
   - 主页面（筛选栏、统计卡片、账单列表、悬浮记账按钮）
   - 普通记账页（金额输入、分类选择、时间选择、备注）
   - AI记账页（录音按钮、预览账单列表）
   - 账单编辑页（回显数据、保存、删除）

3. **统计Tab模块**
   - 页面结构（时间选择、收支切换、分享按钮）
   - 收支总览、分类占比饼图、收支趋势折线图、分类排行榜
   - 分享H5页面（5页上下滑动）

4. **我的Tab模块**
   - 页面结构（个人信息、功能列表）
   - 个人信息编辑（头像、昵称）
   - 账号与安全（修改手机号、微信绑定/解绑）
   - 自定义分类配置（收入/支出Tab、拖动排序、新增分类）
   - 预算设置（月度预算、年度预算自动计算）
   - 记账提醒（开关、时间设置）
   - 隐私协议、关于应用
   - 退出登录

### 不包含

- 后端API对接（使用模拟数据）
- 真实微信登录授权
- 真实短信验证码发送
- AI语音识别功能
- 云端数据同步
